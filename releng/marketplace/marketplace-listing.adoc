== Description

----
The dbUnit Dataset Editor opens dbUnit dataset files as a spreadsheet inside Eclipse.

* Each table is a sheet; each row element is a row; each attribute is a cell.
* Type to edit, Enter and Tab to move, copy and paste rectangular ranges to and from Excel
  or LibreOffice.
* Insert, duplicate, move, and delete rows; add, rename, and delete columns and tables.
* NULL (absent attribute) and empty string are shown and edited distinctly.
* Understands dbUnit semantics: column sensing, empty tables, repeated table segments,
  and DTD-declared columns and tables.
* Warns about dataset content that dbUnit would silently ignore.
* Edits are written back into the XML with minimal text changes: comments, formatting,
  attribute order, and the DOCTYPE are preserved, so version-control diffs stay small.
* Full undo and redo; a Source tab shows the XML, always in sync with the grid.

Version 1 supports the dbUnit flat XML format (FlatXmlDataSet).
Other dbUnit dataset formats are planned for later versions.

dbUnit is a JUnit extension for database-driven projects that puts the database into a known
state between test runs: https://github.com/dbunit/dbunit-extension
----
