Create the listing once (see <<Creating and Updating the Listing>>), then update it after every release

== Description

The Marketplace stores the description as HTML, and it trims the first 200 or so characters into the teaser,
so the opening paragraphs carry the pitch.
Paste this HTML into the description editor's source (HTML) mode.
When the editor has no source mode, paste the rendered text and apply the bullet list with the editor's toolbar.

The description does not depend on the dataset formats: only the paragraph that begins "The plugin currently
supports" names them.
When a format is added, change that sentence here, in `README.adoc`, and in
`features/org.dbunit.eclipse.feature/feature.properties`.

[source,html]
----
<p>Edit dbUnit dataset files like a spreadsheet inside the Eclipse IDE.</p>
<p>The dbUnit Dataset Editor opens dbUnit dataset files as a grid inside Eclipse.</p>
<ul>
<li>Each table is a sheet, its rows are spreadsheet rows, and its values are cells.</li>
<li>Type to edit, Enter and Tab to move, copy and paste rectangular ranges to and from Excel or LibreOffice.</li>
<li>Insert, duplicate, move, and delete rows; add, rename, and delete columns and tables.</li>
<li>NULL and empty string are shown and edited distinctly.</li>
<li>Understands dbUnit semantics: column sensing, empty tables, repeated table segments, and DTD-declared columns and tables.</li>
<li>Warns about dataset content that dbUnit ignores or rejects.</li>
<li>Edits are written back into the file with minimal text changes, so comments, formatting, and the rest of the file stay as they were and version-control diffs stay small.</li>
<li>Full undo and redo; a Source tab shows the text of the dataset, always in sync with the grid.</li>
</ul>
<p>Dataset files open in the editor automatically, and File &gt; New &gt; Other... &gt; dbUnit creates a new one. Requires Eclipse 2024-06 or newer on Java 17 or newer; see the <a href="https://dbunit.github.io/dbunit-eclipse-plugin/usage.html">user guide</a> and the <a href="https://dbunit.github.io/dbunit-eclipse-plugin/install.html">installation notes</a>.</p>
<p>The plugin currently supports the dbUnit flat XML format; other dataset formats are planned.</p>
<p><a href="https://github.com/dbunit/dbunit-extension">dbUnit</a> is a JUnit extension for database-driven projects that puts the database into a known state between test runs.</p>
----

== Creating and Updating the Listing

. Sign in at https://marketplace.eclipse.org with the Eclipse Foundation account that will own the listing.
. Choose *Add Content* in the navigation bar, then *Add a new Solutions Listing*.
. Enter the values of <<Listing Fields>> and the HTML of <<Description>>, and upload the logo and the <<Screenshots>>.
. Submit the form.
The listing waits in the moderation queue until a Marketplace administrator approves it,
normally within 24 hours.
. When the listing is live, add the <<Install Button>>.
. Install the plugin through the Marketplace Client (*Help > Eclipse Marketplace...*, search for "dbUnit") in a
fresh Eclipse of the oldest supported release (2024-06) and of the latest release, and confirm that Eclipse still
starts (see the installation risk in `src/site/asciidoc/install.adoc`).

After each release, edit the listing from *My Marketplace*: set the *Version* to the released version, and review
the description, the Eclipse versions, and the screenshots against the release's entries in `src/changes/changes.xml`.
